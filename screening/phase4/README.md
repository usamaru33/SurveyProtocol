## ai_extraction/ — 該当箇所の抜き出しのテスト

**状態: テスト中。** `rule.md` Rev.31(2026-11-18 承認。抽出で LLM に該当箇所を抜き出させてよい)が根拠。このフォルダの出力は、テストなので抽出の記録に使わない。本番は、協議で Include が確定してから。判定・分類には LLM を使わない(`rule.md` Rev.2)。

**何をするか。** 全文テキスト 1 件を LLM に渡し、17 列それぞれについて、関係する箇所を**原文のまま頁つきで**抜き出させる。値は書かせない。値の記入は抽出担当者が、引用を読んで行う。

| ファイル | 内容 |
|---|---|
| `prompt_v0.3.txt` | プロンプト本文(英語。`run_locate.py` の既定)。v0.2 の英訳で、指示の中身は同じ。`{record_id}` と `{full_text}` を差し込む。**v0.3 ではまだテストしていない** |
| `prompt_v0.2.txt` | プロンプト本文(日本語)。11-13 のテストに使った版。`--prompt v0.2` で再現できる |
| `prompt_v0.2_notes.md` | プロンプトの設計メモ(役割分担、検査、未決の点) |
| `run_locate.py` | 1 件ずつ LLM(`claude -p`)に渡して、応答をそのまま `runs/` に保存する。入力は `fulltext/txt/<record_id>.txt`。出力先は v0.2 が `runs/<model>/`、v0.3 が `runs/<model>_v0.3/` |

使い方(テスト用):

```
python -X utf8 run_locate.py <ids.txt> <run 番号> [--workers N] [--prompt v0.2|v0.3]
python -X utf8 verify_locate.py <model> <run 番号...>
python -X utf8 build_result_xlsx.py <出力.xlsx>
```

**テストの結果(両者 Include の 33 件 × 3 回、claude-sonnet-5-5、プロンプト v0.2(日本語)、費用の目安 約 8.7 ドル):**

- 引用 4,470 個のうち、本文と一致したのは 4,445 個(99.4%)。照合は、空白・PDF の合字・行末ハイフン・ソフトハイフン・曲がった引用符・大文字小文字の違いを無視する。
- 一致しなかった 21 個のうち、AI が原文を変えたのは 14 個(0.3%)。数字の誤写 2、語の脱落・つなぎ合わせ 5、語の置き換え・語順変更 7。残りの 7 個は、PDF から取り出した本文の側で、頁の境目・ヘッダー・表の見出しが文の途中に挟まっていたもの。
- 3 回すべてに共通する箇所がある組は、引用がある 546 組(33 件 × 17 列から 0 件の 15 組を除く)のうち 496 組(91%)。引用の集合が文字列として 3 回とも同じになったのは 123 組(22%)。**「3 回まったく同じ出力」は成り立たない。**
- 3 回とも 0 件だった組が 15(`social_context` 7、`attribution_quote` 6、`scale_factor` と `scale_direction` が 1 ずつ)。本当に記載が無いのか、見落としなのかは、人が本文を読まないと分からない。

**英語版(v0.3)との比較(2026-11-24、同じ 33 件 × 3 回、claude-sonnet-5-5):**

| | v0.2(日本語) | v0.3(英語) |
|---|---|---|
| 引用の数(1 論文・1 回あたり) | 4,470(45.2) | 3,386(34.2) |
| 本文と一致(頁違いを含む) | 4,449(99.5%) | 3,369(99.5%) |
| 本文と一致しない | 21 | 17(原因の分類はまだ) |
| 3 回すべてに共通する箇所がある組 | 496 / 546(91%) | 457 / 533(86%) |
| 3 回で引用の集合が文字列として同じ組 | 123(22%) | 174(31%) |
| 3 回とも 0 件の組 | 15 | 28(v0.2 の 15 組をすべて含む) |
| 費用(99 回) | 8.7 ドル | 6.1 ドル |

- 英語版は引用が 24% 少なく、3 回の出力はやや揃う。照合の一致率は変わらない。
- 日本語版が引用した範囲(文字数)のうち、英語版も引用したのは 62%。逆は 85%。英語版は範囲を絞る方向に変わった。
- 英語版だけ 0 件になった組が 13(`social_context` 6、`attribution_quote` 4、`scale_direction` 2、`n_analyzed` 1)。日本語版の引用を読むと、多くは関係の薄い箇所(仮想の部屋の説明など)だったが、`Rf838e7bc8` の `scale_direction`(「胴とお腹を大きくし、腕を太くした」)は答えになる箇所で、英語版は 3 回とも挙げなかった。
- 照合の数値は `compare_v02_v03.py`(scratchpad で実行、`build_result_xlsx.py` と同じ規則)。出力は `runs/claude-sonnet-5-5_v0.3/`(追跡しない)。

**この結果から言えること。** 再現性は「同じ出力が出る」ではなく、「出力を保存して公開し、引用が本文にあることを誰でも機械的に照合できる」ことで担保する。引用が適切な箇所かどうかと、値の記入は人が行う。数字を AI が誤写した例があるので、人は引用ではなく原文の数字を確かめる。
