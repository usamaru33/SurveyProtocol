## 本文(Slack に貼る用)

```
Kataoka さん、Watanabe さん

自己スケール知覚サーベイの Phase 3b(Title/Abstract)の協議が終わり、全文評価(Phase 4)に進みます。
続きの作業をお願いしたく、ご連絡しました。

【お願いしたいこと】
担当の論文(約100件)の全文を読み、判定シートに記入していただきます。
1件を2名が独立に評価します(あなたの相手は、シートの「担当ペア」列に書いてあります)。

【今回の対象】
・Phase 3b で Include になった論文のうち、重複を統合した149件
・全文PDFは147件を取得済みで、シートの「pdf」列にパスがあります

【判定のしかた】
・PICOS の5基準(P/I/C/O/S)を、それぞれ Y / N / ? で記入 → 判定(Include / Exclude / Unsure)
・Exclude のときは、除外理由(9択)と、根拠のページ・引用を必ず書いてください
・Include か Unsure にした論文のうち、シートで「抽出担当」になっているものは、参加者数・HMD・操作したスケール・従属変数などの事実を所定の列に書いてください(1件5〜10分)
・迷ったら ? にして、メモに何に迷ったかを書いてください(協議で決めます)
・Phase 3b と違って、迷いを Include に倒さなくて構いません。全文評価は最終判断なので、Include と Exclude のミスは同じ重さです
・詳しい基準と手順は、添付の「Phase 4 全文評価 — やることと判断基準」にまとめました。先に目を通してください(10分ほどです)

【お願いしたい約束】
・評価が終わるまで、相手の判定の内容は話さないでください(独立性のため。κ を算出します)
・判定に LLM は使わないでください(読むための翻訳は構いません)

【締切】
配布から3週間後の [ 月 日( )] までに、記入済みの phase4_sheet_<お名前>.xlsx を[返送先]へお願いします。
(1日5件ほどのペースで読むと、100件弱が3週間で終わる計算です。)
もし難しければ、[ 月 日( )] までにご連絡ください。調整します。

【質問・困りごと】
基準の解釈で迷ったときは、その場で決めず ? にしてメモに書いてください。
PDF が別の論文だった・開けない、などは、record_id と一緒に私に連絡してください。

お忙しいところ恐縮ですが、よろしくお願いします。
```
