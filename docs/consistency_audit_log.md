# 文書間の記述統一 — 監査と決定ログ

> **目的:** 複数文書にまたがって食い違っている記述を洗い出し、**どちらが正しいかを著者が決定**し、
> その決定を記録に残す。数値は原則として実データ（`step*.csv` 等）に突き合わせて検証する。
>
> **運用:** 論点ごとに「各文書の記述 / 実データ / 著者の決定 / 適用先」を残す。
> 決定なしに文書を書き換えない。**過去の判断が参照されずに見失われる事故が既に2件
> 起きている**（Rev.14 のフィルタ層維持・S基準のポスター運用）ため、決定は必ずここに集約する。

開始: 2026-08-20

### [3] stage 2 の件数が2系統ある — 「449/439」と「182/144」

| | |
|---|---|
| **記述A** | **449 / 439**（割当上限）— `reviewer_briefing.md` / `reviewer_briefing_preread.md` / `screening/README.md` |
| **記述B** | **182 / 144**（模擬実行、著者Include率53%想定）— `PROGRESS_LOG.md` 2箇所 / `protocol_changelog.md` Rev.17 |
| **実データ** | `assignment.csv` の第2評価者列 = **Kataoka 449 / WATANABE 439**（計888 = 1,052 − 校正164） |

**調査で判明した問題（単なる併存ではなかった）:**

1. **182 + 144 = 326件**。非校正888件に Include 率53%を適用すると **417件**のはずで合わない。
   326件から逆算される Include 率は **63.3%**
2. **割当比率が実データと合わない。** 実データ 449:439 = 50.6:49.4（MD5による決定論的振り分け）
   に対し、模擬実行は 182:144 = 55.8:44.2 と偏っている
3. 算出根拠のスクリプト・出力ファイルとも**現存しない**
4. 一方、同じ表の「旧(Rev.9)」行は正しい（681+696+727 = 2,104 = 1,052×2）。
   **模擬実行の行だけが再現不能**

| | |
|---|---|
| **著者の決定（2026-08-20）** | **182/144 を撤回し、449/439（割当上限）に統一する。** stage 2 の実数は著者の stage 1 完了時に確定するため、仮定に依存した再現不能な予測値を維持する実益がない |
| **適用先** | `PROGRESS_LOG.md` の現状記述2箇所を 449/439 に更新。`protocol_changelog.md` Rev.17 は**履歴なので数値を書き換えず、「再現不能・以後使用しない」の注記を追加** |
| **状態** | ✅ 適用済み |

> 評価者向けの配布物は当初から 449/439 を使っており、**誤った期待を与えてはいない。**
