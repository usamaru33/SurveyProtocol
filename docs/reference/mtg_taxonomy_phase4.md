# 第1部 現状のタクソノミー

## 1.1 タクソノミーとは何か

Phase 4 を通った論文を、**3つの軸**で分類する。
目的は、論文の3つのリサーチクエスチョン(RQ)に数字で答えること。

| 軸 | 英語名 | 一言でいうと | 答える RQ |
|---|---|---|---|
| 軸1 | Intervention modality | **何を操作したか** | RQ1 |
| 軸2 | Evaluation referent | **何を測ったか** | RQ2 |
| 軸3 | Reported arbitration outcome | **著者は何が勝ったと報告したか** | RQ3 |

ルール(すべて【論文】):

- 分類の単位は**研究(study)**。1つの研究が、3軸それぞれに1つずつ値をもらう。
- 3軸は互いに独立。
- **2名が全文を独立に読んで**分類し、不一致は協議で決める。
- 分類のコーディングブックと、研究ごとのコーディングシートを公開する。
- LLM(生成 AI)は分類を含むあらゆる判断に使わない。

---

## 1.2 軸1 — 何を操作したか(Intervention modality)

**問い:** その研究は、どの感覚チャネルを操作したか。

| 値 | 定義 | 例 |
|---|---|---|
| **Unimodal(visual)** | **視覚だけ**を操作した | 下の3種 |
| ├ Visual-Global | アバターの**全身**のサイズを変えた | アバター全体を0.3倍・3倍にする |
| ├ Visual-Local | 身体の**一部**だけのサイズを変えた(他は変えない) | 自分の手だけを大きくする |
| └ Visual-Perspective | 身体は変えず、**視点のパラメータだけ**を動かした | アイハイト(目の高さ)、IPD(両目の間隔)をアバターと独立に操作 |
| **Multimodal (two-way)** | 視覚+**もう1つ**の感覚を**同期**して提示した | 視覚+触覚、視覚+聴覚、視覚+運動 |
| **Multimodal (three-way or more)** | 視覚+**2つ以上**の感覚を提示した | 視覚+触覚+聴覚 |

**判定の順序**(上から順に確認する):

1. 視覚以外に、同期して提示した感覚があるか。
   - ある → **Multimodal**。視覚以外の感覚が1つなら two-way、2つ以上なら three-way or more。
   - ない → 2へ。
2. 描画された**身体のジオメトリ**を変えたか。
   - 全身を変えた(全身と部位の両方を変えた場合も) → **Global**
   - 部位だけ変えた → **Local**
   - 身体は変えず、視点だけ変えた → **Perspective**

補足:

- Global で、カメラが拡縮後の身体に追従してアイハイトや IPD が結果的に動くのは、Perspective にはしない(Global のまま)。
- **action-contingent(自分の動作に連動する)な非視覚の手がかり**(足音、足裏の振動など)は、下位区分ではなく**横断的な着目点**。別途「何件がこの種の手がかりを使うか」を数える。

## 1.3 軸2 — 何を測ったか(Evaluation referent)

**問い:** その研究の測定は、**自分の身体**に向いているか、**周りの世界**に向いているか。

| 値 | 定義 | 例 |
|---|---|---|
| **Self-scale dominant (S)** | 測定が**参加者自身の身体のサイズ**に向いている | 自分の身長の推定、body-image の質問紙、**自分の身体に関連づけた**リーチ・アフォーダンス判断 |
| **World-scale dominant (W)** | 測定が**環境**に向いている | 物体サイズのマッチング、自分から物体までの距離の推定 |
| **Ambiguous/mixed (A)** | 測定が自己と世界を**分けられない**、または**両方を報告しているが、どちらを指すか区別していない** | — |

軸1×軸2のクロス集計が RQ2 の中心になる。
狙い: 「**身体を変える介入**を、**世界向けの測定だけ**で評価している」研究がどれだけあるか(intervention–evaluation gap)を数える。

---

## 1.4 軸3 — 著者は何が勝ったと報告したか(Reported arbitration outcome)

**問い:** 感覚刺激と、頭の中の予想(文脈)がぶつかったとき、**著者は結局どちらが知覚を決めたと報告したか。**

| 値 | その研究の結論 |
|---|---|
| **Stimulus-overriding** | 足音・振動・強い視覚と運動の同期などの**刺激**が予想を上書きし、**身体スキーマが更新された**(自分のサイズ感が変わった) |
| **Context-dominant** | **文脈・予想**が勝った。結果は「**環境が変わった**(世界が縮んだ、など)」または「エラー」と報告された |
| **Conflict/threshold** | 刺激と文脈を**わざとぶつけ**、知覚が**反転する境目**(何倍で逆転するか)を探った |

**最も大事なルール【論文】:** 軸3は「**著者が報告したこと**」を記録する。**私たちの再解析ではない。**
研究の設計が「自己が変わった」と「世界が変わった」を区別できないときは、**区別できないこと自体を記録する**(軸2が A の研究と対応する)。

論文自身が、軸3はもっとも判断が割れやすいと認めている。

## 1.6 前段の適格基準 PICOS(分類の対象になる条件)

| | 基準 |
|---|---|
| P | 健常成人。小児・患者・臨床集団として募集した高齢者は除く |
| I | HMD の VR で、身体や空間のスケールを**操作**した、および/またはスケールに関わる多感覚刺激を**提示**した |
| C | 操作の有無、倍率間、視覚単独と多感覚の**比較**がある |

| S | 実験を報告した実証研究。ポジションペーパー、実験の無い技術報告、総説は除く |

# 第2部 タクソノミーで検討したいこと

## 2.1 先に: この部を読むための用語

| 用語 | ここでの意味 |
|---|---|
| **自己スケール / 世界スケール** | 自己スケール = 自分の体の大きさの感覚。世界スケール = 周りの物体・距離の大きさの感覚。同じ見た目の変化が「自分が大きくなった」とも「世界が小さくなった」とも解釈できるのが、このレビューの出発点 |
| **body image / body schema** | Gallagher の区別。body image = 意識的な身体の像(質問紙で測る)。body schema = 無意識の感覚運動の身体モデル(リーチ・アフォーダンス判断で測る)。論文は**どちらも軸2の S 側**とする |
| **intervention–evaluation gap** | 介入が狙う対象(身体スキーマ)と、評価が測る対象(世界向けの測定)が**ずれている**こと。論文の中心的な発見になる予定 |
| **cue integration (MLE)** | 複数の感覚の手がかりを、**信頼できるものほど重く**混ぜて知覚をつくるという理論。視覚が不確かなとき、触覚や聴覚が効きやすくなる |
| **likelihood / prior** | likelihood = 今の感覚入力。prior = 過去の知識・文脈による予想。軸3の「刺激(Stimulus)対 文脈(Context)」は、この対応を使っている |
| **causal inference** | 「感覚のずれが、自分の変化によるのか、世界の変化によるのか」を脳が推定するという考え方。軸3の背景 |
| **action-contingent** | 手がかりが**自分の動作に連動して**起きること(歩くと足音が鳴る、など)。連動しない音より、身体の感覚を変えやすいと考えられている |
| **Cohen's κ** | 2人の評価者の一致度から、偶然の一致を引いた指標。1に近いほど一致。件数が少ないと、**信頼区間が広い** |
| **study と measure** | study = 1つの研究。measure = 1つの測定。1つの研究が複数の測定・複数の実験を含むことがある |
| **dominant の意味** | 軸2で「S が優勢」と呼ぶときの優勢。**どう決めるかが未定**(2.5) |

## 2.3 ★1 著者が帰属を書いていないとき(軸3)

**なぜ問題か.** 軸3は「著者が報告したこと」を記録する。ところが、**自己の変化か世界の変化かを著者が書かない研究がある**。論文の序論は「帰属を述べる研究は `q` 件、残りは読者に委ねている」と数える設計で、**帰属が書かれていないこと自体を数える**前提になっている。ところが今の3値(Stimulus-overriding / Context-dominant / Conflict-threshold)には、その置き場が無い。

**例.** 身体を2倍にして物体のサイズ推定が変わったが、考察では「サイズ知覚が変わった」としか書かず、自分が変わったのか、世界が変わったのか触れていない。

**選択肢.**

| 案 | 内容 | 得失 |
|---|---|---|
| A | 第4の値 **Not stated** を設ける | 論文の設計と合う。「著者は書いていない」を正直に数えられる |
| B | 推定して3値のどれかに入れる | 「著者が報告したこと」の原則に反する。再解析になる |

**提案: A。** 軸3の原則(著者の報告を記録する)と、論文の数え方の両方に合う。関連して、**効果なし(null)や部分的な更新**も、Not stated か別の扱いにするかを決めたい。

---

## 2.4 ★2 視覚以外だけを操作した研究(軸1)

**なぜ問題か.** 軸1の Unimodal は**視覚が基準チャネル**として固定されている(視覚だけ操作 = Unimodal)。「聴覚だけ操作した」「触覚だけ操作した」研究の置き場が無い。
PICOS の I は「スケールに関わる**多感覚刺激**の提示」も含むので、こうした研究は**適格になりうる**。

**例.** 視覚は一定のまま、足音の音の高さだけを変えて、自分の身体の重さや大きさの感覚を測る。

**選択肢.**

| 案 | 内容 | 得失 |
|---|---|---|
| A | 軸1に **Non-visual only** を足す(視覚は固定、聴覚・触覚などを操作) | 研究を落とさない。論文の「視覚偏重」の主張も数字で言える |
| B | 足さない。この種の研究は不適格とする | 定義は単純。ただし PICOS と矛盾し、スクリーニングをやり直す可能性がある |

**提案: A。** 数が少なくても、「視覚偏重」の主張の根拠になる。

## 2.5 ★3 1本の論文に複数の実験があるとき(コードの単位)

**なぜ問題か.** 論文は study 単位で分類すると書いているが、**1本の論文に複数の実験**があり、実験ごとに操作や測定が違うことがある。

**実例(Superman vs Giant、第4部で議論する論文).** 同じ参加者が3つの実験をしている。

| 実験 | 測ったもの | 軸2 |
|---|---|---|
| 1 | 自分が巨人だと感じたか | S(自己) |
| 2 | 物体の大きさの判断 | W(世界) |
| 3 | 自分の身体サイズの判断 | S(自己) |

1本の論文に S と W の両方がある。軸3も、実験によって結論が違う。

**選択肢.**

| 案 | 内容 | 得失 |
|---|---|---|
| A | **論文を1単位**にし、1つの値を選ぶ(ルールが要る) | 論文の「study 単位」と合う。ただし何を選ぶかの規則が要る |
| B | **実験を1単位**にして分類し、集計のときに論文単位へまとめる | 情報が落ちない。作業は増える。集計の規則が要る |

**提案: B。** 記録は実験単位で行い、論文単位にまとめるときの規則を先に決めておく(軸1は最も多いチャネルの実験を採る、など)。複数実験の論文は少数と見込まれ、作業の増え方は大きくない。

## 2.6 ★4 S と W を両方測った研究(軸2)

**なぜ問題か.** 軸2の A(Ambiguous/mixed)の定義は「測定が自己と世界を分離しない」または「**両方を報告しているが、区別していない**」。では、**S と W の両方を測り、きちんと区別して報告している**研究は何になるのか。定義に書かれていない。
論文の序論は「W のみ `m` 件」「W と自己参照の指標を併用 `p` 件」と数える設計で、**S のみ / W のみ / 併用**の3つが実質必要。

**もう1つの問題: dominant の閾値.** 自己指標が3つ、世界指標が1つの研究は S dominant か。主要アウトカムで決めるのか、測定数の多数決か。

**選択肢.**

| 案 | 内容 |
|---|---|
| A | A に含める(定義を広げる)。Both の区別はできなくなる |
| B | 第4の値 **Both (S+W, distinguished)** を設ける。A は「区別していない」ものだけに戻す |

**提案: B。** 論文が数える「併用」がそのまま出る。dominant は「**著者が主要アウトカムと明示したもの**」で決め、明示がなければ Both とする。

**関連する小さな論点.** 身体所有感の質問紙や固有受容ドリフトは S か。「客観的な運動出力(歩幅など)」は S か W か。(提案: 身体所有感は S。運動出力は何に向いた出力かで決める。要協議)

## 2.7 分類の一致度と体制(検討事項5)

| 論点 | 現状 | 提案 |
|---|---|---|
| κ を付けるか | 論文には「coding book と coding sheet を公開」とだけある。一方で Threats には「κ を報告」と読める記述がある | **付ける。** 約150件を3ペアで分けるとペアあたり約50件で、信頼区間は広いので、一致率と不一致の件数も併記する |
| 誰がやるか | 未定 | **Phase 4 と同じペア。** すでにその論文を読んでいるので、読み直しの時間が減る |
| 事前の較正 | 未定 | **本番の前に10件ほどを全員で分類**し、基準のずれを直す。スクリーニングで κ が初回低かった経験に照らして |
| コーディングブック | 論文は公開と書いたが、未作成 | この資料の第1部と第2部が素地。較正後に確定版をつくる |

## 2.8 Multimodal の「同期」の最低条件(軸1)(検討事項6)

**なぜ問題か.** Multimodal は「視覚+もう1つの感覚を**同期**して提示」。では、時間が合っていない音がただ流れているだけ、全条件で同じ音が鳴っているだけの場合は?

**提案.** 次の両方を満たすとき Multimodal とする。
(1) その感覚が**操作の一部**(条件間で変えた、または操作に連動して提示した)である。
(2) 視覚と**時間的に対応**している。
ベースライン条件で、全員に同じものが提示されているだけの感覚は数えない。

# 第3部 Phase 4 でお願いしたいこと

## 3.1 概要

| | |
|---|---|
| **やること** | 担当の論文の**全文を読み**、5つの基準に Y/N/? を付けて、Include/Exclude を決める |
| **対象** | 148件(取得済み。重複を統合した149件のうち1件は未取得で、後から追加) |
| **担当件数** | 著者 100件、Kataoka さん 98件、Watanabe さん 98件。1件を**2名**が独立に評価 |
| **締切** | 配布から**約3週間**(1日5件ほど) |
| **返すもの** | 記入済みの Excel シート `phase4_sheet_<お名前>.xlsx` |
| **渡すもの** | 自分のフォルダ(判定シートと、担当分の全文 PDF) |

守ってほしいこと:

- **評価が終わるまで、相手の判定を話さない**(独立性のため。κ を算出します)。
- **判定に LLM を使わない**(読むための翻訳は構いません)。
- 迷ったら `?` にして、memo に何に迷ったかを書く。**Phase 3b と違い、迷いを Include に倒さない。**

## 3.2 1件ごとの手順

1. 全文の PDF を開く(抄録だけで判定しない)。
2. **6つの列**に Y / N / ? を記入する(下の表)。
3. 判定(Include/Exclude/Unsure)は、シートが自動で出す。食い違う行には警告が出る。
4. Exclude のときは、**除外理由**(9択)と**根拠のページ・引用**を書く。
5. Include か Unsure で、シートの「抽出担当」が自分の行は、**事実の抽出列**を書く(1件5〜10分)。

## 3.3 判断基準

| 列 | Y(満たす) | N(満たさない) | ?(判断できない) |
|---|---|---|---|
| **P** 対象者 | 健常成人(大学生・大学院生含む) | 小児、患者、臨床集団として募集した高齢者 | 年齢・属性が全文のどこにも無い |
| **I_hmd** | HMD の没入型 VR | デスクトップ、CAVE、実環境のみ | **AR/MR は第4部の相談事項**。決まるまで `?` + memo に「MR」 |
| **I_scale** | 自己・環境のスケールに**関係する**操作または刺激がある | スケールと無関係(所有感の誘導だけ、パーソナルスペースだけ、触覚フィードバックだけ、距離知覚の評価だけ) | 関係が全文でも判断できない |
| **C** 比較 | スケール操作の有無、倍率間、視覚単独と多感覚の比較 | 比較する条件が無い | — |
| **O** 評価指標 | 定量データ(サイズ推定、距離、アフォーダンス、**身体所有感の質問紙**、運動出力) | 感想・インタビューだけ | — |
| **S** デザイン | 人を対象にした実験の報告。**ショートペーパー、ポスター、学位論文も実験があれば Y** | 総説、ポジションペーパー、実験の無い技術提案、デモのみ | — |

特別な扱い(すべて確定):

- **混合サンプル:** 健常成人の結果を**分けて報告**していれば、その部分で判断(memo に書く)。分けていなければ N。
- **身体所有感だけの研究:** O は Y。ただし I_scale が N なら除外になる。
- **I_scale の線引き:** 基本は「自己・環境のスケールに関係あるもの」だけ。関係しなければ N。

## 3.4 判定の決め方(シートが自動で出す)

| 状態 | 判定 |
|---|---|
| 1つでも N がある | **Exclude** |
| N が無く、? がある | **Unsure** |
| 6列すべて Y | **Include** |

Unsure は協議で必ず Include か Exclude に決める(最終判定に Unsure は残らない)。

## 3.5 除外理由(1つだけ選ぶ)

複数当てはまるときは、**上のものを選ぶ**。判定には影響しない(報告を揃えるための規則)。

| 順位 | 理由 |
|---|---|
| 1 | 重複(同一研究の別報告) |
| 2 | スコープ外(主題が無関係) |
| 3 | S: 原著論文でない(総説、書籍、実験の記述が無い抄録) |
| 4 | S: ユーザー実験が無い |
| 5 | P: 対象者が不適合 |
| 6 | I: HMD-VR でない |
| 7 | I: スケール操作/多感覚刺激が無い |
| 8 | O: スケール知覚の測定が無い |
| 9 | その他(**C が無い場合はここ**。memo 必須) |

## 3.6 事実の抽出列(Include/Unsure のうち、抽出担当の行だけ)

**論文に書かれた事実だけ**を書く。分類の語彙(Global/Self-scale など)は使わない。
時間が足りなければ、必須の10列だけでよい。

| 必須 | 任意 |
|---|---|
| 参加者数(全体)、属性・年齢・性別、HMD の機種、何のスケールを変えたか、倍率・値、視覚以外の感覚、課題、従属変数、主な結果(1文)、帰属の記述(原文引用+ページ) | 分析に使った人数、縮小/拡大、視覚以外の提示内容、動作に連動?、社会的文脈、個人差の扱い、効果なしの条件? |

書き方: 複数あるときは `;` で区切る。論文に無いときは `記載なし`、当てはまらないときは `該当なし`。引用は原文のまま、末尾に `(p.N)`。

## 3.7 困ったとき

| 状況 | どうする |
|---|---|
| 基準の解釈に迷う | その列を `?` にして memo に書く |
| 全文に書かれていない(年齢など) | `?` + memo「記載なし」。推測で Y にしない |
| 同じ研究の別論文らしい | memo に record_id を書いて著者に知らせる |
| PDF が別の論文・開けない | 判定せず、record_id と一緒に著者へ連絡 |
| 論文ではない(会議録の序文など) | 「S: 原著論文でない」+ memo |

詳細は `phase4_reviewer_guide.md`。

## 4.1 Superman vs Giant(`6X75UZKY`)を戻すか

**経緯.**

| 項目 | 内容 |
|---|---|
| 論文 | Piumsomboon ら (2018), *Superman vs Giant: A Study on Spatial Perception for a Multi-Scale Mixed Reality Flying Telepresence Interface*, IEEE TVCG |
| 落ちた段階 | Phase 3a(キーワード除外)。語 `mixed reality` / `mr` に該当。**人間は一度も判定していない** |
| 妥当性 | ルール(Cat1)どおりで、違反ではない。ルール自体の境界例に当たった |
| 同様の例 | `mixed reality`/`mr` だけで落ちた19件のうち、スケール操作に関わるのはこの1件だけ(残り18件は MR の応用・システム論文) |

**内容(全文を読んだ要約).** 14名、3つの実験(同じ参加者)。IPD・移動ゲイン・アイハイトを操作。IPD を大きくするほどモノを小さく知覚し(実験2)、巨人と感じるには IPD と高さの**両方**を大きくする必要がありそう(実験3)。

**注意点.**

- 参加者14名、ほぼ男性。実験3は部分的な支持。
- 文脈は MR のテレプレゼンス。実験1・2は VR、実験3は see-through の映像。
- **後から1件だけ戻すと、選択バイアスを疑われやすい。** 根拠は「MR 語での設計上の除外が、スケール操作の論文を落とす境界例に当たった」ことと、MR 語で落ちた19件を同じ基準で見直したこと。

**選択肢.**

| 案 | 内容 | 得失 |
|---|---|---|
| **A(提案)** | 次の Rev. として Phase 3a の除外から戻し、**Title/Abstract の判定(3名)**に回す | 人間の判定を経る。他の除外と整合する。前例あり(Venue で落ちた既知文献を DOI で戻した) |
| B | 戻さず、Threats に境界例として書くだけ | プロトコル変更なし。ただし、スケール操作の論文を判定せずに落とす |
| C(非推奨) | Phase 4 に直接入れる | 最短だが、人間が一度も判定していない論文を通す |

**決めること:** A/B/C のどれか。A の場合、判定の担当(3名か、Phase 3b と同じ設計か)。

## 4.3 論文の見出しと貢献の書き方

| # | 論点 | 気になる点 |
|---|---|---|
| 1 | 論文の見出しは何か | 現在の筋は「gap(介入と評価のずれ)の定量化」。**gap が小さかった場合**(自己参照の併用が多かった場合)にどう書き換えるか |
