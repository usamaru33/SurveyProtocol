# 判定カード — Phase 3b Title/Abstract スクリーニング

> **判定中に手元に置くための1枚。** 判定に必要な情報だけを集めた**写し**であり、
> **新しい基準は一切導入していない**（Rev.19 の凍結に抵触しない）。
> 経緯・根拠・出典の説明は `reviewer_briefing.md`、手続きの定義は `screening_protocol.md`。
>
> **正の所在:** 適格性基準 = `docs/protocol/rule.md` §Phase 4 PICOS ／
> 除外理由の語彙 = `scripts/make_screening_xlsx.py` `EXCLUDE_REASONS` ／
> 優先順位 = `scripts/make_review_app.py` `EXCLUDE_PRIORITY`（生成時に語彙との一致を検査）。
> **食い違いを見つけたらこのカードではなく上記を正とすること。**

**締切: 2026年8月31日（月）** — 記入したシートをそのまま返送。

---

## 1. 判定の3値と、自分の1票の効き方

方式は **liberal accelerated**（1名の Include で通す / Exclude には2名）。

| 判定 | 意味 | この1件のその後 |
|---|---|---|
| **Include** | 残す | **確定で Phase 4（全文評価）へ。** 第2評価者には回らない |
| **Exclude** | 除外 | 第2評価者が確認する。2名が Exclude で初めて落ちる |
| **Unsure** | 保留 | Exclude と同じく第2評価者へ回り、協議対象になる |

**校正セット（★）も判定基準は同じ。** 「テストだから厳しく」は不要。

---

## 2. 判定基準（PICOS を Title/Abstract レベルに緩めたもの）

| | 基準 | 補足 |
|---|---|---|
| **P** 対象者 | 健常成人 | 小児・高齢者（臨床対象）・患者は除外 |
| **I** 介入 | **HMD を用いた VR 環境**での身体・空間スケール操作、および多感覚刺激の提示 | |
| **C** 比較 | スケール操作の有無、異なる倍率間、視覚単独 vs 多感覚 | **この段では使わない。**「比較群が書かれていない」を理由に Exclude しない |
| **O** 評価指標 | 自己・環境のスケール変容を測る**定量的データ**（主観的サイズ推定、距離知覚、アフォーダンス判断、身体所有感、客観的運動出力） | |
| **S** 研究デザイン | 客観的な**ユーザー実験**にもとづく実証研究 | |

---

## 3. 迷ったときの3原則

1. **除外できると確信できないものは残す**（Include に倒す）。全文を読めば分かることをこの段で切らない
2. **迷ったら `Unsure`。** 無理に二択にしない
3. 協議でも解決しなければ **Include** に倒して Phase 4 へ送る（再現率優先）

> 誤 Exclude は**回復不能**（二度と検討されない）／誤 Include は次段の手間が増えるだけ。

---

## 4. 迷いやすいケースの既定の扱い

| ケース | 扱い |
|---|---|
| 視覚のスケール操作だけで、多感覚が無い | **Include。** これが本レビューの主要な調査対象 |
| 距離知覚だけを測っていて「自己サイズ」を測っていない | **Include。** O 基準に距離知覚が明記されている |
| アイレベル（視点の高さ）だけを操作している | **Include** |
| 2ページのポスター・アブストラクト | **実験があれば Include**（→ §5 の `S: 原著論文でない` の解釈） |
| 心理系の雑誌で、VR が主題に見えない | HMD を使っていれば Include 側。確信が持てなければ **`Unsure`** |
| 要旨が無くタイトルだけ | 判断できなければ **`Unsure`** |
| 手法は合うが被験者が患者 | `P: 対象者が不適合` で Exclude |
| VR酔い・プレゼンス**だけ**が主題 | スケール知覚の測定が無ければ `O:` で Exclude。**併せて測っていれば Include** |

## 5. 除外理由（Exclude のとき必須・9択）

**複数該当するときは、下表の上にあるものを1つだけ記録する（Rev.24）。併記は不要。**
原理は「**上位ほど、下位の基準を評価する前提そのものが崩れている**」。重要度の順ではない。

| 優先 | 選択肢 | 閲覧アプリの数字キー | 該当するもの |
|---|---|---|---|
| **1** | `重複(同一研究の別報告)` | **8** | 既に対象に含まれている研究の別報告・拡張版・重複登録 |
| **2** | `スコープ外(主題が無関係)` | **7** | 基準を当てるまでもなく、本レビューの主題と無関係 |
| **3** | `S: 原著論文でない` | **6** | 総説・サーベイ・抄録のみ・ポスター・基調講演・書籍など |
| **4** | `S: ユーザー実験が無い` | **5** | 技術提案・デモ・シミュレーションのみで、実証的なユーザー実験を伴わない |
| **5** | `P: 対象者が不適合` | **1** | 健常成人でない（小児・高齢者・患者・特定の専門職集団など） |
| **6** | `I: HMD-VR でない` | **2** | デスクトップ画面・AR/MR・CAVE・実環境のみなど、HMD を用いた VR でない |
| **7** | `I: スケール操作/多感覚刺激が無い` | **3** | 身体・空間スケールの操作も、多感覚刺激の提示も行っていない |
| **8** | `O: スケール知覚の測定が無い` | **4** | 自己・環境のスケール変容を測る定量指標が無い |
| **9** | `その他` | **9** | 上のどれにも当てはまらない。**メモ必須** |

> ⚠️ **数字キーの並びは語彙の表示順であって優先順位ではない**（配布済みシートの並びを凍結しているため）。
> 例: `1` = `P: 対象者が不適合` は優先5、`8` = `重複` は優先1。

**`S: 原著論文でない` の解釈（2026-08-20 補足）** — 語彙の文言には「ポスター」が入っているが、
これは**実験を報告していない文献種別**を指す。**実験を報告しているポスター/ショートペーパーは Include。**
ページ数は除外理由にしない。**シートの文言は配布時のまま変更していない。**

**`C`（比較対象）は選択肢に無い。** 比較条件は要旨に書かれないことが多く、
ここで落とすと誤除外になるため、判断は Phase 4 へ送る。

## 6. 判定に使わない情報

| 情報 | 理由 |
|---|---|
| `ランク`（CORE / SJR） | Phase 2 で基準を満たし済み。二重に効かせない |
| `概念群`（0〜3） | 読む順序のトリアージ専用。**この数値で機械的に除外しない** |
| `取得経路`（database / snowballing） | PRISMA の左右カラム別報告用。**判定基準は両者で同一** |
| `校正セット`（Y / N） | κ の算出対象かの記録。判定基準は同じ |
| `要旨の出所` が `enriched` | 外部補完した要旨。**通常の要旨と同じように扱う** |
| 閲覧アプリのハイライト・日本語訳 | 表示補助。**判定は原文に対して下す** |

---

## 7. 記入するもの

**Excel（`sheet_<id>.xlsx` の「判定」シート、★の3列だけ）**

1. **判定** — Include / Exclude / Unsure
2. **除外理由** — Exclude のときのみ必須。§5 の優先順位で**1つ**
3. **メモ** — 任意。ただし除外理由が「その他」のときは必須

**閲覧アプリ（著者用・任意）** — `i`=Include / `u`=Unsure / `1`〜`9`=Exclude+理由、
`j`/`k` 移動、`m` メモ、`z` 取り消し、`h` ハイライト、`t` 訳、`r` 凡例、`?` ヘルプ、`e` 書き出し、
`s` 途中保存 / `l` 読み込み（端末をまたぐとき）。
スマホでは画面下のタップ操作バーで判定し、Exclude は理由のボトムシートから選ぶ。

**独立性:** 他の評価者のシートは開かない。判定についての事前相談もしない。迷ったら相談せず `Unsure`。
