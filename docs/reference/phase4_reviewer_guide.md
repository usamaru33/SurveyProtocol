## 1. 全体の流れ

| 段 | 誰が | 内容 |
|---|---|---|
| 1. シート作成 | 著者 | 判定シートと割当表を生成(`scripts/make_fulltext_sheets.py`。作成済み) |
| 2. 独立に評価 | 担当ペアの 2 名 | 全文を読み、基準ごとに Y / N / ?、判定、除外理由、根拠を記入 |
| 3. 返送・集計 | 著者 | 記入の検査、ペアごとの Cohen's κ と平均、基準別の一致率、不一致の一覧 |
| 4. 協議 | 担当ペア(必要なら 3 人目) | 不一致と Unsure を話し合い、**Include か Exclude に必ず決める**。決着しなければ 3 人目を加えて多数決 |
| 5. 最終判定 | 著者 | 最終判定を確定し、PRISMA の数字(除外理由別の件数)を出す |
| 6. 分類 | 別途 | Include 論文を Taxonomy(3 軸)で分類する。**判定とは別の作業**(`taxonomy_coding_definition.md`) |

**独立性のため:** 評価が終わるまで、**担当ペアの相手と判定の内容を話さない**。他の人のシートは存在しない(各シートには自分の担当分だけが入る)。

## 2. 評価者がやること(1 件ごとの手順)

1. **全文を開く。** `pdf` 列のパスの PDF を読む。抄録だけで判定しない。
   - 読む場所の目安: 抄録 → 実験方法(参加者・装置・条件)→ 測定項目 → 結果。
   - 本文が会議録の序文・書籍の章などで、研究そのものが見つからないときは、そのことをメモに書く。
2. **5 基準を順に判定する。** `P_check`・`I_hmd`・`I_scale`・`C_check`・`O_check`・`S_check`(I は 2 列に分けた【確定】)に、**Y / N / ?** を記入。基準は §3。
3. **`decision`(判定)は自動で出る。手入力しない。**(「判定(自動)」の 1 列だけ。式でロックしてある)
   - 6 列(P・I_hmd・I_scale・C・O・S)がすべて Y → `Include`
   - 1 つでも N → `Exclude`(N と ? が混ざる場合も Exclude)
   - N が無く、? がある → `Unsure`
   - 6 列に空欄があるうちは、判定は空のまま。
4. **Exclude のとき、`reason`(除外理由)は自動で入る。`evidence` は必ず書く。**
   - `reason`: N の付いた基準から、優先順位(§4)で最も上の 1 つが自動で入る。**別の理由にしたいときだけ、プルダウンで選び直す**(重複・スコープ外・「S: 原著論文でない」は自動では入らない)。
   - `evidence`: 根拠のページと一文の引用。空だと赤くなる。協議の時間が減る。PRISMA の監査にも使う。
5. **境界例は `memo` に必ず書く。** Include の場合も、迷った点があれば書く。
6. **自分の判定が Include か Unsure の論文は、事実の抽出列を書く**(担当ペアのうち、割当表の `extractor` に書かれた 1 名。形式は §3.5)。
   論文に書かれた事実だけを書き、分類の語彙(軸 1〜3)は使わない。後で全文を読み直さずに済ませるため。
7. **全件が終わったら**、返送の前に未記入の行がないか確認する。

**LLM は判定に使わない**(`rule.md` Rev.2)。翻訳ツールで読むことは構わないが、判定そのものは自分で行う。【要承認: 翻訳を使った場合のメモ】

## 3. 判断基準(PICOS の運用)

論文の PICOS(Table 2)を、全文で判断できる水準に操作化したもの。**基準の運用は 2026-10-19 に著者が確定した**【確定】(AR/MR だけ MTG で決める)。

### P — 対象者(Population)

| | 内容 |
|---|---|
| **Y** | 参加者が健常成人。大学生・大学院生・スタッフは健常成人とみなす |
| **N** | 小児、臨床集団として募集した高齢者、患者(摂食障害・疼痛・脳卒中など)。特定の専門職集団を対象にした訓練・臨床研究 |
| **?** | 参加者の年齢・属性が全文のどこにも書かれていない |
| 例外 【確定】 | **混合サンプル:** 健常成人の結果を**分けて報告**していれば、その部分で判断して Y(memo に書く)。分けていなければ N |

### I — 介入(Intervention)

2 つの条件を**両方**満たすとき Y。

- **I_hmd:** HMD を使った没入型 VR である。デスクトップ画面・実環境のみ・CAVE・プロジェクション → N。**AR / MR(see-through)は** 【MTG】 — 決まるまで `?` とし、memo に「MR」と書く。
- **I_scale** 【確定】: **自己または環境のスケールに関係する**操作・刺激がある。次のいずれか。
  - 身体・身体部位・アバターのサイズ、視点の高さ、IPD、環境や物体のスケールを**操作**している。
  - 身体サイズの知覚に関わるように設計された多感覚刺激を**提示**している(論文の表現: multisensory stimuli bearing on bodily scale)。
  - **基本は自己・環境のスケールに関係あるものだけ。** 多感覚刺激だけで、スケールと無関係な研究(身体所有感の誘導、パーソナルスペース、触覚フィードバック、距離知覚の評価だけ)は **N**。
    Rev.27 の境界例 18 件(これらの種類の論文)も、スケールに関係しなければ N。MTG で、この種の論文は入れないと決めた。
  - スケールとの関係が全文を読んでも判断できないときは `?` にして memo に書く(§7 の判断ログに載せる)。

### C — 比較対象(Comparison)

| | 内容 |
|---|---|
| **Y** | 次のいずれかがある: スケール操作の有無の比較 / 異なる倍率間の比較 / 視覚単独と多感覚の比較。被験者内・被験者間のどちらも可 |
| **N** | 単一条件の記述研究。比較する条件が無い |

C の N には、現在の語彙に対応する除外理由が無い。除外理由は自動で `その他` になる【確定】(語彙は増やさない)。C だけが N のときは、memo に書かなくてよい(自動の `その他` と分かるため)。

### O — 評価指標(Outcome)

| | 内容 |
|---|---|
| **Y** | 自己または環境のスケール変容を測る**定量**データがある: 主観的サイズ推定、距離知覚、アフォーダンス判断、身体所有感(質問紙を含む)、客観的運動出力 |
| **N** | 定量データが無い(感想・インタビューだけ) |
| 例外 【確定】 | **身体所有感だけでも O は Y**(論文 PICOS の O に身体所有感が含まれるため)。ただし I_scale が N なら除外される |

### S — 研究デザイン(Study design)

| | 内容 |
|---|---|
| **Y** | 人の参加者を対象にした客観的なユーザー実験の報告。**会議のショートペーパー・ポスターでも、実験を報告していれば Y**(Rev.20)。**学位論文(修士・博士)も実験を報告していれば Y**(査読の有無は問わない)【確定】 |
| **N** | 総説・サーベイ・ポジションペーパー・技術提案のみ・シミュレーションのみ・デモのみ・実験の無い抄録・書籍 |

### 3.5 事実の抽出列(自分の判定が Include か Unsure の論文)の形式 【確定】

- **誰が書く:** 担当ペアのうち、割当表の `extractor` 列の 1 名(ペア内で record_id を整列し、交互に割り当てる。誰が実行しても同じ結果)。もう 1 名は書かない。
  協議のとき、書いた人以外が読んで食い違いを指摘する。
- **何を書く:** 論文に**書かれている事実**。解釈・分類(Visual-Global、Self-scale など)は書かない。
- **所要時間の目安:** 1 件あたり 5〜10 分。
- **記号:** 論文に書かれていない → `記載なし` / 質問が当てはまらない → `該当なし` / 空欄は「未記入」(検査で警告)。
- **複数あるとき:** `;` で区切る。引用は原文のまま(言語を変えない)、末尾に `(p.N)` を付ける。

| 列 | 必須 | 形式 | 書き方 |
|---|---|---|---|
| `n_total` | ● | 整数 | 全参加者数(除外前)。例: `24` |
| `n_analyzed` | | 整数 | 分析に使った人数。`n_total` と同じなら空でよい |
| `population` | ● | 自由 1 行 | 属性・年齢・性別。例: `大学生・大学院生; 22.1±2.3 歳; 女 12 / 男 12` |
| `device` | ● | 自由 1 行 | HMD の機種。複数は `;`。例: `HTC Vive; Oculus Rift CV1` |
| `scale_target` | ● | 語彙(複数可) | 何のスケールを変えたか: `身体全体` / `身体部位` / `視点の高さ` / `IPD` / `環境` / `物体` / `なし(操作せず測定のみ)` |
| `scale_factor` | ● | 自由 1 行 | 倍率・値。例: `身体 0.3×・1×・3×` / `アイハイト 1.0・1.7・2.5 m`。無ければ `記載なし` |
| `scale_direction` | | 語彙 | `縮小` / `拡大` / `両方` / `該当なし` |
| `non_visual` | ● | 語彙(複数可) | 視覚以外に提示した感覚: `聴覚` / `触覚` / `運動同期(歩行・身体動作)` / `前庭` / `その他` / `なし` |
| `non_visual_detail` | | 自由 1 行 | 何をどう提示したか。例: `足音の高周波を増幅`。`non_visual` が `なし` なら空 |
| `action_contingent` | | `Y` / `N` / `?` | 視覚以外の手がかりが、参加者自身の動作に連動して生じるか |
| `task` | ● | 語彙(複数可) | `距離推定` / `サイズ推定・マッチング` / `リーチ・把持` / `歩行・移動` / `アフォーダンス判断` / `身体サイズ判断` / `質問紙のみ` / `その他` |
| `outcome_measures` | ● | `名称(種別)` を `;` で並べる | 種別は `主観報告` / `質問紙` / `行動` / `生理`。例: `物体サイズ推定(行動); 身体所有感 SoE(質問紙)` |
| `social_context` | | 語彙 | `単独` / `他アバターあり` / `記載なし` |
| `individual_diff` | | 語彙 | 参加者特性(身長・VR 経験・性別・年齢)を: `報告のみ` / `分析に使った` / `記載なし` |
| `null_effect` | | `Y` / `N` / `?` | 操作の効果が有意でなかった条件があるか |
| `main_finding` | ● | 1 文 | 著者が報告した主な結果と方向。日本語 1 文。例: `身体を拡大すると物体が小さく見えた` |
| `attribution_quote` | ● | 原文引用+`(p.N)` | 変化を自己の変容と環境の変容のどちらに帰属したかの記述。無ければ `記載なし` |

必須(●)は 10 列、任意は 7 列。時間が足りないときは必須だけでよい。

## 4. 除外理由(1 件につき 1 つ)

Phase 3b の語彙(9 択)をそのまま使う。**複数当てはまるときは、下の表で最も上のものを 1 つ選ぶ。**
判定には影響しない(報告を揃えるための規則)。基準別の列には、当てはまった基準をすべて残す。

| 順位 | 選択肢 | 当てはまるとき |
|---|---|---|
| 1 | `重複(同一研究の別報告)` | 対象の別の論文と同じ研究 |
| 2 | `スコープ外(主題が無関係)` | 基準を当てるまでもなく主題が別 |
| 3 | `S: 原著論文でない` | 総説・サーベイ・書籍・基調講演・**実験の記述が無い**抄録 |
| 4 | `S: ユーザー実験が無い` | 技術提案・デモ・シミュレーションのみ |
| 5 | `P: 対象者が不適合` | 健常成人でない |
| 6 | `I: HMD-VR でない` | デスクトップ・AR/MR・CAVE・実環境のみ |
| 7 | `I: スケール操作/多感覚刺激が無い` | どちらも行っていない |
| 8 | `O: スケール知覚の測定が無い` | 定量指標が無い |
| 9 | `その他` | 上のどれにも当てはまらない。C が N のときは自動で入る(memo 不要)。それ以外で自分で選んだときは **memo 必須** |
| 追加 | `全文を入手できない` | 判定ではなく状態。PRISMA の「reports not retrieved」。**入手できない文献を抄録だけで判定しない** |

理由は「どこで脱落したか」の記録で、上にあるものほど、下の基準を問う前提が崩れている(総説に「対象者は健常成人か」を問えない、など)。詳細は `reviewer_briefing.md` §3.3。

## 5. 迷ったとき

| 状況 | どうする |
|---|---|
| 基準の解釈に迷う | その基準を `?` にして、memo に何に迷ったかを書く。Unsure になり、協議で決める |
| 全文のどこにも書かれていない(参加者の年齢など) | `?` にして、memo に「記載なし」と書く。推測で Y にしない |
| 同一研究と思われる論文が複数ある | memo に record_id を書いて著者に知らせる(統合は著者が決める) |
| PDF が別の論文・読めない | 判定せず、著者に連絡する(過去に PDF が別の論文だった例がある) |
| 論文が研究ではない(会議録の序文など) | `S: 原著論文でない`。memo に理由 |

**迷いを `Include` や `Exclude` で隠さない。** Phase 3b と違い、Phase 4 の Unsure は協議で必ず決着するので、迷いを正直に出してよい。

## 6. 協議と最終判定

- 不一致(Include と Exclude)と、どちらかが Unsure の件を、**担当ペアの協議**で決める。
- 最終判定は **Include か Exclude のみ**。Unsure は残さない。
- 決着しなければ**3 人目を加えて多数決**。
- 協議の結果は、最終判定・協議メモとともに判定シートに残し、成果物として保存する。
- 報告するもの: ペアごとの Cohen's κ と平均、**基準別の一致率**、除外理由別の件数、最終採択件数。
  対象は約 150 件でペアあたり約 50 件のため κ の信頼区間が広い。κ だけでなく一致率と不一致の件数も報告する。
