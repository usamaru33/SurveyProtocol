# 日本語要約・訳の作り方(Phase 4 閲覧アプリ用)

論文 1 本につき `fulltext/ja/<record_id>.json` を 1 つ書く。入力は `fulltext/txt/<record_id>.txt`
(PDF から抽出した全文。`[p.N]` が頁の区切り)。

## 目的と限界
読解の補助。**判定(Include/Exclude)の材料にしない**。レビュアーは必ず PDF の原文で確認する。
だから「原文にあることだけ」を書く。推測・一般知識での補完・好意的な言い換えをしない。
論文に書かれていないことは「記載なし」と書く。数値・条件名・尺度名は原文のまま(英語名を併記してよい)。

## JSON の形(キーは変えない。値は日本語。UTF-8 で書く)
```json
{
  "id": "R...",
  "abstract_ja": "要旨(Abstract)の日本語訳。原文に忠実に全文訳。要旨が無ければ「記載なし」",
  "summary": {
    "purpose": "研究の目的・問い(1〜2 文)",
    "method": "手法の概要。何を操作し、何を測ったか(2〜4 文)",
    "participants": "参加者数・属性(例: 大学生 24 名、男 12/女 12、平均 21 歳)。分析に使った人数が違えば併記",
    "conditions": "実験条件。HMD の種類、スケール操作の対象(身体全体/手/IPD など)と倍率、視覚以外の刺激の有無、被験者内/間",
    "measures": "従属変数・尺度(質問紙名、行動指標、生理指標)",
    "results": "主な結果(2〜4 文)。著者がスケール知覚の変化の原因をどう説明しているかがあれば 1 文で",
    "limits": "要約者の不確かな点・読み取れなかった箇所(無ければ空文字)"
  },
  "cues": {
    "P":       {"note": "対象者に関する該当箇所の要約(成人か、患者や小児でないか)", "page": "p.3"},
    "I_hmd":   {"note": "HMD を使った没入型 VR か。実験環境、AR/see-through かどうか", "page": "p.4"},
    "I_scale": {"note": "自己または環境のスケールを操作しているか。何をどう操作したか", "page": "p.4"},
    "C":       {"note": "比較条件があるか(倍率違い、操作の有無、視覚のみ vs 多感覚など)", "page": "p.5"},
    "O":       {"note": "スケール知覚を測る定量指標があるか", "page": "p.6"},
    "S":       {"note": "人を対象にした実験(ユーザー実験)か。総説・提案・シミュレーションのみでないか", "page": "p.2"}
  }
}
```
- `cues.*.page` は原文の頁(抽出テキストの `[p.N]` に合わせる)。見つからなければ空文字。
- `cues` は「どこを見れば判断できるか」の道案内。Y/N の判定そのものは書かない(「満たす」「除外」と断定しない)。
  「〜と記載(p.4)」「〜の記載が見当たらない」の形にする。
- 文章は簡潔に。1 項目 1〜3 文。
- 抽出テキストが壊れている・本文が極端に短い(総説の 1〜2 頁だけ等)ときは、`summary.limits` に書く。
