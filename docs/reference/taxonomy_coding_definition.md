## 1. 軸 1 — 介入モダリティ (Intervention modality) → RQ1

【論文 L909-920】

### 1.1 値と定義

| 値 | 定義 | 例 |
|---|---|---|
| **Unimodal (visual)** | 視覚情報**のみ**を操作する | 下の 3 つの下位区分 |
| ├ Visual-Global | アバターの**全身**の描画ジオメトリを拡大縮小する。アイハイトと IPD はカメラが拡縮後の身体に追従するので結果的に動くが、**別コードにはしない** | アバター全体のサイズ |
| ├ Visual-Local | **身体の一部**のジオメトリだけを拡縮し、他は変えない。**全身と部位の両方を拡縮した研究は Global** | 手のサイズ |
| └ Visual-Perspective | 身体ジオメトリは**変えず**、視点パラメータだけをアバターと独立に動かす | アイハイト、IPD をアバターの実寸から切り離して操作 |
| **Multimodal (two-way)** | 視覚+**もう 1 つ**の感覚チャネルを**同期**して提示 | Visual-Tactile / Visual-Motor / Visual-Auditory |
| **Multimodal (three-way or more)** | 視覚+**2 つ以上**の感覚チャネル | 例: Visual-Tactile-Auditory(rule.md) |

### 1.2 下位区分の判定の流れ 【読み取り】(論文の規則をそのまま順に並べたもの)

1. 視覚以外に、同期して提示した感覚チャネルがあるか → あれば Multimodal(チャネル数で two-way / three-way or more)
2. なければ Unimodal(visual)。レンダリングされた身体ジオメトリを変えたか
   - 全身を変えた(全身+部位の両方を含む)→ **Global**
   - 部位だけ → **Local**
   - ジオメトリは変えず視点パラメータだけ → **Perspective**

### 1.3 関連する背景 (Background の記述 L338-381)

- Global の代表: Being Barbie 系(van der Hoort 2011)、child body(Banakou 2013)、avatar scaling(Hartman 2020)、Gulliver(Serino 2020)
- Local の代表: own hand の拡大(Linkenauger 2013)、Ogawa 2017/2018
- Perspective の代表: eye height(Leyrer 2011, Wolf 2020)、eye height と IPD の分離(Kim & Interrante 2017)
- **action-contingent(自分の動作に連動する)な非視覚手がかり**は、下位区分ではなく**横断的な着目点**(L369-381)。足音の音(Tajadura-Jiménez)、落下物のオーディオ-触覚、足裏振動(Kitazaki 2021)など。論文は「`k` 件がこの種の手がかりを使う」と数える設計(L209, L381)

### 1.4 【未定】

- **非視覚のみ(例: 聴覚だけ、触覚だけ)の研究の置き場がない。** 「Unimodal=視覚のみ」と定義されており、視覚が基準チャネルとして固定されている。→ 軸 1 に非視覚カテゴリを設けるか(phase4_sheet_design §7 の保留事項)
- 「同期(synchronised)」の最低条件。時間的に同期していない/非随伴の音や触覚が付いているだけの場合に Multimodal とみなすか
- 視覚と同じ刺激の「提示」と「操作」の区別。ベースライン条件で提示されるだけのチャネルは数えるか(比較される独立変数になっているチャネルか)
- 1 本の論文に複数の実験・条件があるときの単位(論文は study 単位。複数実験で最も多チャネルの条件を採るのか、全実験を通じて採るのか)

## 2. 軸 2 — 評価の参照対象 (Evaluation referent) → RQ2

【論文 L922-928】

### 2.1 値と定義

| 値 | 定義 | 例(論文記載) |
|---|---|---|
| **Self-scale dominant (S)** | 測定が**参加者自身の身体のサイズ**に向いている | 自分の身長の推定、body-image 尺度、**身体に関連づけた**リーチ/アフォーダンス判断 |
| **World-scale dominant (W)** | 測定が**環境**に向いている | 物体サイズのマッチング、egocentric distance の推定 |
| **Ambiguous/mixed (A)** | 測定が両者を**分離しない**、または**両方を報告しているが参照先を区別していない** | — |

軸 2 は intervention–evaluation gap(身体スキーマを狙った介入を、外界向けの測定だけで評価している)を数えるための軸。軸 1 × 軸 2 のクロス集計が RQ2 の中心(L1149-1157)。

### 2.2 補足 (Background L317-323)

- Gallagher の区別: **body image**(意識的・評価的な表象 → 質問紙、図形評定尺度)と **body schema**(非意識的な感覚運動系 → 固有受容ドリフト、リーチ/アフォーダンス判断)。
- 論文は**どちらも軸 2 の self-referred 側**とする。ただし「スケール操作が両者に同じ影響を与えるとは限らない」として、軸 2 の内部で区別を残す含み。

### 2.3 【未定】

- **コードの単位が study か measure か。** 1 研究が S の測定と W の測定を**別々に**報告する場合、論文の定義では「両方を報告しているが参照先を区別していない」ものだけが A に読める。区別して両方報告している研究が A なのか、S+W なのかが書かれていない。一方、序論は「W のみ `m` 件、W と自己参照指標を併用 `p` 件」と数える設計(L213-215)で、**S のみ / W のみ / 併用**の 3 区分が実質必要
- Ownership(身体所有感)の質問紙や proprioceptive drift が S か(O 基準で「身体所有感だけで足りるか」という Phase 4 の保留とも連動)
- 「dominant」の閾値(主たる測定がどちらかをどう決めるか)。主要アウトカムで決めるのか、測定の数の多数決か
- 客観的運動出力(歩幅など)の扱い

## 3. 軸 3 — 報告された調停結果 (Reported arbitration outcome) → RQ3

【論文 L930-941】

### 3.1 理論的位置づけ

ベイズ的な cue integration(MLE、式 (1))と causal inference(式 (2))の枠組み(Section 2.3, L385-435)。現在の**感覚刺激(Stimulus / likelihood)**と**過去の知識・文脈(Context / prior)**のどちらが最終的に知覚を支配したか、という**結果の着地点**で分類する。

### 3.2 値と定義

| 値 | 定義(その研究はどう結論づけたか) |
|---|---|
| **Stimulus-overriding** | 足音や振動、強い visuomotor synchrony などの**物理的刺激**が事前知識を上書きし、**身体スキーマが更新された**(自己サイズが変容した)と報告 |
| **Context-dominant** | トップダウンの知識や**文脈手がかり**が勝ち、報告された結果が**環境の変容(miniaturisation reading)またはエラー**だった |
| **Conflict/threshold** | 刺激と文脈を**意図的に衝突**させ、知覚が**反転する境界**(どの倍率・条件で逆転するか)を探った |

### 3.3 最も重要な規則

> **軸 3 は「著者が報告したこと」を記録する。我々の再解析ではない。** 研究の設計が 2 つの解釈(自己が変わった/世界が変わった)を区別できないときは、**それ自体を記録する**。そうした研究は軸 2 で A に分類されるものと一致する。(論文 L939-941)

- 論文はこの軸が最も判断が割れやすいと自認している:「著者が報告した結果を符号化しており、報告が曖昧なことがある」(Threats to Validity, L1360-1361)。

### 3.4 【未定】(phase4_sheet_design §7 の保留事項に対応)

- **著者が帰属を明示していないとき**の既定コーディング規則。推定してコードするのか、第 4 の値 **"Not stated"** を設けるのか。論文は「帰属を述べる研究は `q` 件、残りは読者に委ねる」(L225-229)と数える設計であり、**Not stated を数えることを前提にした書き方**になっている
- 3 値のどれにも当たらない結果(効果なし/null、部分的な更新など)の置き場。例: 非視覚手がかりを使ったが null だった研究(L209-210)
- Conflict/threshold の「意図的」の判定(倍率を複数段階に振っただけで足りるか、反転点を目的に探索したことが要るか)
- 軸 3 は「刺激を与えた」研究が前提に見える。刺激の操作がなく測定だけの研究(例: 既存の身体サイズでの判断)をどうするか

## 8. ミーティングで決めたいこと(論点一覧)

優先度の高い順。★は分類の開始前に必須。

1. ★ **軸 3 に "Not stated" を設けるか**(著者が帰属を明示しないとき)。設けない場合の既定規則
2. ★ **軸 1 に非視覚のみのカテゴリを設けるか**。設けない場合、非視覚のみの研究は適格か
3. ★ **コードの単位**(study 単位か、実験/測定単位か)と、複数実験を含む論文の扱い
4. ★ **軸 2 の S+W 併用の扱い**(A に含めるか、独立した値にするか)と「dominant」の閾値
5. **分類に κ を付けるか**、付けるなら Cohen's κ(ペア)か、一致率も併記か。件数は約 150 のため信頼区間は広い
6. **誰がどのペアで分類するか**(Phase 4 と同じ割当か)
7. **事前の較正**(件数、較正後に基準を改訂する場合の記録方法)
8. §5 の抽出項目を、Phase 4 の判定シートに同時に入れるか(phase4_sheet_design §7 の提案)
9. Multimodal の「同期」の最低条件
10. rule.md の §3.3 を論文の定義に合わせて改訂するか(§7 の差)

## 9. 論文で議論したいこと・コントリビューションとして述べられそうなこと

分類結果(特に軸1×軸2、軸3)が出てから確定する内容を含む。
凡例: 【論文】= 論文に既に書かれている主張・設計 / 【仮説】= 論文が事前に立てている予測(データで検証、外れうる) / 【候補】= 分類データが出れば言えそうだが、論文にはまだ書かれていない。【候補】は私の提案で、合意が要る。

### 9.1 現在の論文が掲げるコントリビューション 【論文 L248-271】

| # | コントリビューション | 依存するもの |
|---|---|---|
| C1 | PRISMA 2020 準拠の系統的レビュー。検索・スクリーニングを再実行できる形で公開し、**LLM を適格性判断に使わない**ので、すべての採否が人間の判断に帰属する | 既に確定(スクリーニング完了) |
| C2 | **3軸の分類体系**(介入モダリティ・評価の参照対象・報告された調停結果)。intervention–evaluation gap を**数えられる**ようにする | 分類の確定(§8 の論点) |
| C3 | 分類軸に沿ったコーパスの**定量的な特徴づけ**(時系列トレンド、HCI と心理学の収束) | 分類+出版年・Venue・分野 |
| C4 | **信頼性重み付けの cue integration** による、「どのとき非視覚の action-contingent な手がかりが支配するか」の予測と、設計者向けの**非視覚パラメータの整理**(音: ピッチ・残響・遅延、触覚: 周波数・振幅) | 軸1・軸3+§5 の抽出項目 |
| C5 | **準ゴールドスタンダードの known-item test**。パイプラインのどこで関連研究が失われるかを定量化し、**目標(再現率80%)に届かなかったことも含めて**報告する | 確定済み(step 0: 76.5%) |

### 9.2 論文の中心的な主張(議論の軸) 【論文】

1. **Intervention–evaluation gap(中心的発見になる予定、L1396-1397)。** 身体スキーマを狙った介入が、外界向けの測定だけで評価されている。この場合、測定値の変化は「自己が変わった」「世界が変わった」の両方と整合し、設計上は区別できない。
2. **視覚偏重。** 介入の多くが光学配列(アイハイト、IPD、アバター寸法、手のサイズ)の操作に限られ、他のチャネルから来る action-contingent な手がかりは少ない。「ギャップは、何が試されたかにある」(L210)。
3. **帰属の未報告。** 自己と世界の両方を測っても、どちらに帰属したかを述べない研究が多い。これは測定の問題である前に**報告の問題**(L225-229)。
4. **Miniaturisation の読み。** 縮尺・文脈によっては「自己の拡大」ではなく「世界の縮小」と報告される。どの倍率・どの文脈でそうなるか(RQ3)。
5. **拡大と縮小の非対称**(Serino 2020: 縮小では body-image が動き、拡大では動かない)と、**事前知識が身体とともに更新されない**こと(Pouke 2021: 人間スケールの物理のほうが妥当と判断された)。

### 9.3 論文が事前に立てている仮説(検証のため、外れてもそのまま報告) 【仮説】

| 仮説 | 検証に使う軸・変数 | 箇所 |

### 9.4 分類データが出れば言えそうなこと 【候補】(論文には未記載、合意が要る)

- **軸1×軸2のクロス表の空欄。** 「身体を操作し、自己参照で測る」「非視覚を加え、自己参照で測る」のセルが空なら、そのまま研究課題になる(論文 L278-279 が「空のセルは Section 9 で扱う」としている)。

### 9.5 Discussion / Threats で議論する点 【論文 L1264-1388】

### 10.2 論文の内容(全文を読んだ要約。2026-10-19、IEEE Xplore の PDF)

- 目的: MR での多スケール遠隔協働のための「飛行テレプレゼンス」。巨人になった感覚を作る条件を調べた。
- 参加者: 14 名(男性 13 名、女性 1 名、22〜39 歳)。**3 つの実験とも同じ参加者**。アバターは出していない。
- 操作: IPD、移動ゲイン、アイハイト。video see-through の HMD を使用。

| 実験 | 内容 | 結果 |
|---|---|---|
| 1 | 動的 IPD(Giant)と固定 IPD(Superman) | 動的 IPD のほうが自分を巨人と感じた(p=.0196)。シミュレータ酔いに差なし |
| 2 | 物体サイズの判断(IPD 3 水準×移動ゲイン) | IPD が大きいほど物体を小さく知覚(H3 支持)。移動ゲインは有意でない(H4 不支持)。手がかりが豊富だと周囲のスケールの影響を受けた(H5 支持)が、IPD の影響が主 |
| 3 | 自己の身体サイズ(IPD×アイハイト、ステレオ映像) | 屋内は IPD も高さも倍で差。屋外は IPD 4 倍・高さ 2 倍で差。**IPD だけ・高さだけでは不十分**。H6・H7 は部分的な支持 |

著者の結論: IPD の操作はサイズ知覚に影響し、移動ゲインは影響しない。see-through HMD で巨人の感覚を作るには、IPD と高さの両方を大きくする必要がありそう。Giant と Superman の両モードを提供し、IPD の限界までを IPD で、残りの高さ差を移動ゲインで補うことを推奨。

### 10.3 分類に当てはめた場合 【読み取り】

- 軸 1: Visual-Perspective(IPD・アイハイト)。移動ゲインは視覚以外の運動に関わる操作で、**Visual-Motor に当たるか**は論点。
