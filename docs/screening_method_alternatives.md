## 2. 各候補の検討

### A. 完全二重独立スクリーニング

**全件を2名が独立に判定し、不一致を協議する。** システマティック・レビューの標準。

| | |
|---|---|
| **長所** | 最も感度が高い（見落とし3%）。査読で説明が要らない |
| **短所** | 工数が2倍。Phase 3b では 1,052×2 = 2,104件の判定が必要だった |
| **判定** | **Phase 4 では採用**（対象件数が大幅に少なく、最終判断であるため）。Phase 3b では工数上不可能だった |

> Phase 3b で採らなかったのは工数だけが理由です。**Phase 4 で採っていることが、
> 「工数のために質を捨てたのではない」ことの証拠**になります。この対比は論文で使えます。

### B. liberal accelerated（現行の Phase 3b）

**1名が Include にすれば通す。Exclude には2名を要する。**

| | |
|---|---|
| **起源** | Khangura et al. 2012 [R2] |
| **公式な位置づけ** | **Cochrane Rapid Reviews Methods Group が推奨** [R3][R4] |
| **実証** | ML併用のシミュレーションで誤除外 0〜3件（0〜14%）、節約 中央値26時間 [R5] |
| **長所** | 誤除外の方向にだけ二重化を集中させる。C5 の非対称性に直接対応 |
| **短所** | 元は **rapid review** の手続き（C4 と衝突）。誤除外はゼロではない |

**弱点の自覚（査読で先に出すべき点）:**

- [R4] は本方式について「**does not save much time and is often difficult to implement in SR software**」と述べている。**工数削減を主たる根拠にすると崩される**
- [R5] の誤除外 0〜14% は無視できない幅。ML併用の条件下での数字である点にも注意

> **正しい正当化:** 工数ではなく **C5（誤除外の回復不能性）**を主根拠にすること。
> 「除外の方向にだけ2名を要求することで、回復不能なエラーだけを二重化した」が論の芯。

### C. 単独スクリーニング

**却下済み。** 見落とし13%（感度86.6%）[R1] は systematic review の水準を満たしません。
[R1] 自身が「rapid review では有効な選択肢」と条件付きで述べており、C4 に反します。

### D. 一部を二重→残りを単独（Cochrane RRMG モデル）

**記録の一部（例: 20%）を2名で判定し、一致度を確認してから残りを1名で判定する。**

[R4] の推奨:
- 「We recommend dual assessment on a proportion of records, **for example, 20%**」
- 「reviewer agreement is high（**at least 80% agreement**）」を確認してから単独へ移行
- 「After this dual-screening phase, reviewers must **discuss and resolve conflicting decisions**」

| | |
|---|---|
| **本プロジェクトとの関係** | Cochrane は **D と B を組み合わせて**推奨している（20%二重 + 残り単独 + **除外は全件を第2評価者が確認**） |
| **相違点** | 本プロジェクトは校正セット **15%**（推奨例示の20%を下回る）。また **80%一致のゲートが無い** |

> ### ⚠️ ここが本設計への最も具体的な指摘材料
>
> **論点1: 15% < 20%。** シートは配布済みで変更不可。
> **論点2: 一致度のゲートが無い。** κ を測る仕組みはあるが、基準を満たさなかった場合の
> 取り決めが定義されていない。
>
> **反論の骨子（こちらの方が保守的である）:** Cochrane のモデルは
> 「20%を二重 → **残りは1名のみ**」。本設計は「**全1,052件を著者が判定 + 除外は全件を
> 第2評価者が確認**」であり、**二重化の総量はむしろ多い**。20%という数字は
> 「単独へ切り替える前のゲート」としての値であって、本設計の校正セットは
> **κ 推定のための集合**であり役割が異なる。
>
> ただし「15%という値の根拠が記録されていない」ことは事実なので、
> **Threats に明記する**（`methodology_rationale.md` §8-C2）。

### E. 基準限定の単独除外（Nama アルゴリズム）★ Phase 4 の有力候補

**「この理由での除外なら1名でよい」と基準ごとに切り分ける。**

Nama et al. 2021 [R6] は24件のシステマティック・レビューで検証し、
**感度低下 0% だった除外基準**を特定しています。

| 感度低下0%の除外基準 |
|---|
| conference abstract（会議抄録） |
| ineligible age group（対象年齢が不適合） |
| case report / case series |

| | |
|---|---|
| **長所** | **実証にもとづいて**単独判定の適用範囲を限定できる。決定論的に運用可能（C2適合） |
| **短所** | 検証は小児医療領域のレビュー24件。**HCI/VR 領域での妥当性は未検証** |
| **本プロジェクトへの適用** | **P基準（健常成人でない）は "ineligible age group" に近い。** Phase 4 で「P基準による除外は1名でよい」とする根拠になりうる |

> ⚠️ **ただし注意:** 「conference abstract」を単独除外可としてよいのは、その領域で
> 会議抄録が対象外の場合です。**本サーベイは実験を報告するポスター/ショートペーパーを
> Include する**（Rev.14 / Rev.20）ため、**この基準はそのまま流用できません。**
> 領域差を無視して援用すると、まさに Rev.20 で直した矛盾を再発させます。

### F. ML による読む順序の最適化（全件は読む）⚠️ C1 の解釈が必要

**能動学習で「関連しそうな順」に並べ替える。ただし全件を人が読む。**

[R7] によれば、能動学習モデルは **WSS@95 で 63.9〜91.7%**（関連文献の95%を見つけた時点で
残りを読まずに済む割合）。ただしこれは**早期停止を前提とした指標**です。

> ### ★ 重要な区別
>
> | | 機械が何をするか | C1適合 |
> |---|---|---|
> | **並べ替えのみ（全件読む）** | 読む順序を変えるだけ。**適格性の判定はしない** | ⚠️ 解釈次第 |
> | **並べ替え + 早期停止** | 残りを**機械が除外する**（＝適格性判定） | ❌ 明確に違反 |

**本プロジェクトは既に非ML の優先順位付けを行っています。** シートは `概念群`
（3概念群のヒット数 0〜3）の降順に並べてあり、シート内に「**読む順序の目安であり、
この数値で判定しないでください**」と明記しています。これは F の「並べ替えのみ」と
同じ構造です。

| | |
|---|---|
| **論点** | `rule.md` Rev.2 の「AI/LLM」が、古典的機械学習（TF-IDF + ナイーブベイズ等）を含むか。原稿の文言は "**no large language model**" であり、LLM に限定されている |
| **判断** | **著者の決定が必要。** 全件を読む限り適格性判定は人間のみだが、「AIを使っていない」という主張の厳密性は下がる |
| **推奨** | **Phase 3b・Phase 4 では採用しない。** 主張の明快さを優先する。将来の再実行で件数が桁違いに増えた場合の選択肢として記録に残す |

### G. ML + 早期停止

**❌ C1 違反。** 停止時点以降の文献は**機械が除外を決めた**ことになります。
[R8] の系統的な検討でも、停止基準の較正（confidence が実際に当たっているか）は
未解決の課題とされています。**採用しません。**

### H. LLM による判定・事前フィルタ

**❌ C1 違反。** 本プロジェクトが査読で最も強く主張している特徴を自ら壊します。
**検討の余地はありません。**

> 記録として: `protocol_changelog.md` Rev.2 でこの方針が確定し、
> 記入見本の作成時にも「著者の分の判定を実行してほしい」という依頼を、
> この方針を理由に断っています（`PROGRESS_LOG.md` 2026-08-17(3)）。**一貫しています。**

### I. クラウドソーシング

Cochrane Crowd 等の外部の多人数に判定させる。[R1] の実験基盤がこれです。

**✕ C3 により不可。** 3名体制の研究プロジェクトでは運用できません。
また外部者に PICOS の解釈を委ねることになり、本サーベイのように
**主題判断が微妙な領域**（自己スケール vs 環境スケール）には適しません。

### J. 不一致の第3者解決

**採用済み。** 不一致と Unsure を `consensus_worklist.csv` に抽出し協議、
**決着しなければ Include に倒して Phase 4 へ送る**（再現率優先）。

## 3. Phase 4 への提案

Phase 4 は未確定です。現行案（Rev.9 / Rev.17）は **A（完全二重独立）**。

| 案 | 内容 | 感度 | 工数 |
|---|---|---|---|
| **A（現行案）** | 全件を3名中2名が独立評価、ブロック分担 | 最高 | 最大 |
| **A + E** | 基本は A。ただし **P基準（健常成人でない）による除外は1名で可**とする | ほぼ同等（[R6] で該当基準は感度低下0%） | 削減 |
| **B** | Phase 4 にも liberal accelerated を適用 | 低下 | 最小 |

**推奨: A を維持する。**

理由は `rule.md` に既に書かれているとおりで、**Phase 4 は最終判断であり
Include / Exclude の双方に同等の慎重さを要する**ためです。対象件数も Phase 3b より
大幅に少なく、工数上の制約が緩い。

> **A + E は検討に値しますが、慎重に。** [R6] の検証領域（小児医療）と本サーベイ（HCI/VR）は
> 異なり、特に「conference abstract」基準は**本サーベイの方針と正面から衝突します**
> （実験を報告するポスターは Include）。**流用するなら P基準に限定し、その旨を明記すべき**です。
>
> ただし工数削減の必要が生じていない現時点では、**A を素直に維持するのが最も説明しやすい**。

## 4. 論文で「なぜ他を採らなかったか」を書くときの骨子

```
Phase 3b:
  単独スクリーニング(C)は見落とし13%[R1]で systematic review の水準を満たさない。
  完全二重独立(A)は 1,052×2 件の判定が必要で、3名体制では現実的でない。
  そこで liberal accelerated(B)[R2] を採った。これは Cochrane RRMG が推奨する
  手続き[R3][R4]であり、誤除外が回復不能・誤包含は次段で救えるという
  エラーの非対称性に対応する。

  ただし本サーベイは rapid review ではない。[R1] の結論は rapid review を
  条件としており、そのまま援用できない。除外側を二重化することで
  単独スクリーニングとの差を埋める、というのが本研究の論証である。

  Cochrane は二重判定する割合として20%を例示する[R4]が、本研究は15%(164件)とした。
  ただし本設計は「残りを単独で判定する」のではなく全件を著者が判定しており、
  二重化の総量は Cochrane モデルより多い。15%という値自体に統計的検出力計算の
  裏付けは無く、この点は限界として報告する。

Phase 4:
  最終判断であり Include / Exclude 双方に同等の慎重さを要するため、
  通常の二重独立評価(A)とする。

機械学習・LLM:
  適格性判定には一切用いない。読む順序のトリアージには決定論的な
  概念群スコアを用いるが、この値で除外は行わない。
```
