# 進捗ログの追記

`SurveyProtocol/docs/PROGRESS_LOG.md` の末尾「## セッションログ」セクションに、当日の日付見出しで追記する。
（プロトコル文書は 2026-07-21 に `docs/` へ集約済み。README.md と known_items*.md はルート据え置き。）

## 書式

```markdown
### YYYY-MM-DD
- やったこと（実行したスクリプト、変更したファイル、得られた数値）
- 判断・決定事項とその理由
- 次回やること（具体的に、優先度順）
```

## ルール

- **数値は必ず具体的に**書く（「だいぶ減った」ではなく「2,858 → 1,784件」）。
- スクリーニング基準を変更した場合は、「まだやっていないこと」「既知の課題・メモ」セクションも合わせて更新する。
- 完了した項目は「まだやっていないこと」から「完了していること」へ移動する。
- パイプライン数値が変わった場合は `README.md` の PRISMA 数値も更新する。
- 追記後、ユーザーにコミットするか確認する（コミットメッセージは日本語でよい）。
- **PR を出すなら `/survey-pr` を通す。** ログの追記だけでは他文書との食い違いは直らない。
